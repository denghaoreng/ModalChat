# SillyTavern 插件开发总览

## 什么是 SillyTavern 插件？

SillyTavern（简称 ST）是一个面向 LLM 用户的本地界面。插件（Extensions）是扩展 SillyTavern 功能的主要方式，它们运行在浏览器环境中，拥有对 DOM、JavaScript API 和 SillyTavern 上下文（Context）的几乎不受限制的访问权限。

> 📖 **官方文档**: https://docs.sillytavern.app/for-contributors/writing-extensions/

## 插件架构

SillyTavern 的插件系统分为两大部分：

### 1. 前端 UI 扩展（UI Extensions）
- 运行在浏览器中，使用 JavaScript 编写
- 可以操作 DOM、监听事件、修改 UI
- 通过 `getContext()` API 与 ST 核心交互
- 文件位于 `public/scripts/extensions/` 目录下

### 2. 服务端插件（Server Plugins）
- 运行在 Node.js 服务端
- 扩展 ST 后端的 API 和功能
- 使用不同的机制

> 本文档聚焦于**前端 UI 扩展**开发。

## 插件目录结构

一个标准的 SillyTavern 插件包含以下文件：

```
my-extension/
├── manifest.json      # 插件清单（必需）
├── index.js           # 主 JS 入口（必需）
├── style.css          # 样式文件（可选）
├── settings.html      # 设置面板 HTML 模板（可选）
└── i18n/              # 国际化文件（可选）
    └── zh-cn.json
```

### 模块拆分建议

插件只需一个 `index.js` 作为入口，但**复杂插件必须拆分为多模块**，否则会导致：

- 单个文件数千行，难以阅读和维护
- 多人协作时冲突频繁
- 无法按功能域独立测试
- 重用逻辑被迫复制粘贴

#### 最小拆分（适用于 400 行以下的简单插件）

```
my-extension/
├── manifest.json       # 引用 index.js
├── index.js            # 入口：生命周期钩子、事件注册/注销
├── data.js             # 数据层：加载/保存/CRUD 操作
├── ui.js               # UI 渲染：生成 HTML、绑定事件
├── utils.js            # 工具函数：ID 生成、格式化、防抖等
├── style.css
└── settings.html
```

#### 推荐拆分（适用于大多数插件）

当插件涉及多个独立功能域时，按功能拆分为子目录更清晰：

```
my-extension/
├── manifest.json       # 插件清单
├── index.js            # ★ 入口：生命周期、全局事件注册、导航栏创建
├── style.css           # 全局样式
├── settings.html       # 扩展设置模板
│
├── core/               # ★ 核心数据层（与业务逻辑分离）
│   ├── data.js         # 数据层 facade：加载、保存、模块数据访问器
│   ├── file-storage.js # 文件 I/O：JSON 读写、路径管理
│   └── default-data.js # 默认值常量
│
├── shell/              # ★ 导航栏与消息处理（UI 框架层）
│   ├── drawer.js       # 导航栏 Drawer 创建 + 标签页切换
│   └── message-handler.js # SillyTavern 事件回调集
│
├── shared/             # 共享工具（被多个模块调用）
│   ├── utils.js        # 工具函数
│   ├── file-service.js # 文件服务（上传/删除）
│   └── ui-components.js# 可复用 UI 组件
│
├── nav-module-a/       # 「功能模块 A」标签页
│   ├── domain/         #   数据层 CRUD
│   │   ├── entity-a.js #   实体 A 的增删改查
│   │   └── entity-b.js #   实体 B 的增删改查
│   ├── ui/             #   UI 层
│   │   ├── index.js    #   主渲染入口 + 子导航调度 + 事件绑定
│   │   ├── tab-a.js    #   子标签 A 渲染
│   │   ├── tab-b.js    #   子标签 B 渲染（含搜索/排序/分页）
│   │   └── settings.js #   设置面板
│   ├── popup/          #   弹窗
│   │   ├── batch.js    #   批量操作弹窗
│   │   └── help.js     #   帮助/教程弹窗
│   └── renderer/       #   渲染引擎（如轮播、队列）
│       ├── bubble.js   #   聊天气泡渲染
│       └── persist.js  #   持久化与恢复
│
├── nav-module-b/       # 「功能模块 B」标签页（独立子模块）
│   ├── domain/         #   数据层
│   ├── ui/             #   UI 层
│   └── scorer/         #   自定义引擎子模块
│       ├── index.js    #   re-export hub
│       ├── core.js     #   ★ 核心计算逻辑
│       ├── algorithm-a.js # 算法 A
│       ├── algorithm-b.js # 算法 B
│       └── cache.js    #   缓存
│
└── nav-module-c/       # 「功能模块 C」标签页
    ├── ...             #   类似结构
```

拆分原则：

| 原则 | 说明 |
|------|------|
| **入口薄** | `index.js` 只做生命周期、事件注册、导入调度，不做业务逻辑 |
| **数据与 UI 分离** | CRUD 放在 `domain/`，渲染和事件放在 `ui/` |
| **按功能域拆子目录** | 每个导航标签页对应一个独立子目录，内部再按职责细分 |
| **引擎/算法分离** | 计算密集或可独立测试的逻辑放在独立子模块（如 `scorer/`） |
| **共享代码提升** | 被多个模块调用的工具函数提升到 `shared/` |
| **每个文件一个职责** | 如果一个文件需要滚动才能看完，就应该拆分 |

拆分方式：入口文件 `index.js` 使用 ES Module `import` 导入子模块，`manifest.json` 只引用 `index.js`：

```javascript
// index.js — 薄入口
import { initDrawer } from './shell/drawer.js';
import { registerEvents } from './shell/message-handler.js';
import { loadSettings } from './core/data.js';

export async function init() {
    loadSettings();
    initDrawer();
    registerEvents();
}
```

SillyTavern 会以 `<script type="module">` 方式加载入口文件，因此模块内 `import` 语句可以正常使用。

## 两种安装方式

### 1. 为所有用户安装（服务端级）
将插件仓库放在 `public/scripts/extensions/third-party/` 目录下。要求重启 SillyTavern 服务端。

### 2. 为当前用户安装（用户级）
通过 SillyTavern 的 "Download Extensions & Assets" 菜单下载安装。数据存放在 `data/<user-handle>/extensions/` 目录下。

> 本地开发时，建议将插件放在 `public/scripts/extensions/third-party/` 目录下以简化路径引用。

---

## 快速开始

1. 在 `public/scripts/extensions/third-party/` 下创建你的插件文件夹
2. 创建 `manifest.json` 和 `index.js`
3. 在 `index.js` 中导出 `init` 函数（由 `activate` 钩子调用）
4. 使用 `renderExtensionTemplateAsync()` 加载 HTML 设置面板
5. 使用 `eventSource.on()` 监听事件
6. 重启 SillyTavern 或刷新页面查看效果
