# ModalChat 多模态聊天插件文档

## 概述

ModalChat 是 SillyTavern 的第三方扩展插件，融合了 chat-images 和 MatchScoring 两个插件，并新增统一文件管理器。

## 快速开始

1. 将 `ModalChat` 文件夹放入 `SillyTavern/public/scripts/extensions/third-party/`
2. 首次启动时自动迁移旧插件数据
3. 在 SillyTavern 导航栏中点击 "多模态聊天" 图标使用
