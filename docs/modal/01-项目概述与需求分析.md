# ModalChat 插件 — 项目概述与需求分析

> 编写日期：2026年7月25日 | 最后更新：2026年7月27日

## 一、项目背景

ModalChat（多模态聊天）是 chat-images 和 MatchScoring 两个 SillyTavern 第三方插件的融合升级版本，并在此基础上新增了大量高级功能。

### 1.1 融合动机

| 方面 | chat-images | MatchScoring | 融合后 |
|------|-------------|-------------|--------|
| 核心功能 | 正则匹配插入图片 | NLP 评分匹配媒体文件 | 两者兼具 |
| 文件管理 | 规则内嵌图片上传 | 独立文件 CRUD | 统一文件管理器 |
| 配置体系 | 内嵌在规则设置 | 配置界面 + 通用配置 | 整合为通用配置 + 子标签页 |
| 数据存储 | extensionSettings | extensionSettings | 多文件独立存储（JSON） |

### 1.2 设计目标

1. **统一入口** — 一个导航栏入口，四个一级标签页，每个标签页可包含多个子标签页
2. **统一文件管理** — 独立文件管理器，所有模块通过文件注册表引用文件
3. **保留各自逻辑** — chat-images 匹配引擎和 MatchScoring 评分引擎各自独立
4. **增量功能** — 新增轮播插位配置、果冻弹跳物理引擎、动画类型编辑器等高级功能
5. **可扩展存储** — 支持 5 万+ 文件注册表条目，按目录分文件存储

## 三、关键设计决策

### 3.1 文件引用模型

chat-images 和 MatchScoring **不再直接操作服务端文件**，所有文件操作委托给文件管理器：

```
用户上传文件
      │
      ▼
┌──────────────────┐
│  文件管理器       │  → 上传到服务器（生成唯一标识文件名）
│  (唯一负责文件IO)  │  → 写入文件注册表 { id, 真实文件名, 展示名, 路径, ... }
└──────────────────┘
      │
      ▼
┌──────────────────┐
│  文件注册表       │  → chat-images 规则引用注册表 ID
│  (中央索引)       │  → MatchScoring 匹配引用注册表 ID
└──────────────────┘
```

### 3.2 唯一文件名格式

- chat-images 源文件：`ChatImages_YYYYMMDD_HHmmss_XXXXXX.ext`
- MatchScoring 源文件：`MatchScoring_YYYYMMDD_HHmmss_XXXXXX.ext`
- 文件管理器上传：`MM_YYYYMMDD_HHmmss_XXXXXX.ext`

### 3.3 文件存储路径

所有用户文件存储在 SillyTavern 的 `/user/files/` 路径下，按目录组织。

### 3.4 数据存储架构

**重要变更**：ModalChat **不再使用** `extensionSettings['modal-chat']` 存储数据。改为在 `/user/files/` 下存储多个独立 JSON 文件：

| 文件 | 内容 |
|------|------|
| `ModalChat_settings.json` | 目录列表、文件夹元数据、通用配置、最后标签页 |
| `ModalChat_chat-images_data.json` | 聊天图片模块（角色集/规则集/规则） |
| `ModalChat_match-scoring_data.json` | 匹配打分模块（文件列表/权重/配置/动画类型等） |
| `ModalChat_reg-index.json` | 注册表轻量索引 { id: directory } |
| `ModalChat_dir_{hash}.json` | 按目录分文件的注册表条目 |

### 3.5 海量文件支持

注册表按目录分文件存储，只有当前目录的数据加载到内存，支持 5 万+ 条注册表条目。轻量索引（约 50 字节/条）始终在内存中。

## 四、与旧插件的差异

| 方面 | 旧插件 | ModalChat |
|------|--------|-----------|
| 文件上传 | 各自实现 | 统一由文件管理器处理 |
| 文件引用 | 直接存储文件路径 | 通过文件注册表 ID 引用 |
| 批量操作 | 各自实现 | 统一在文件管理器中 + 批量新增弹窗 |
| 导航栏 | 各自独立图标 | 单个图标 + 一级/二级标签页体系 |
| 数据存储 | 各自 extensionSettings 键 | 多文件独立 JSON（/user/files/ 下） |
| 匹配结果展示 | 简单文本 | 轮播插位 + 动画类型 + 聊天气泡渲染 |
| 视频/音频支持 | 仅图片 | 图片 + 视频 + 音频全支持 |
| 果冻弹跳效果 | 无 | 基于 SVG feDisplacementMap 的物理引擎 |
| 轮播配置 | 无 | 多层插位 + 类型筛选 + 时长控制 |
