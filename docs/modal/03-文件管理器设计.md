# ModalChat 插件 — 文件管理器设计

> 编写日期：2026年7月25日

## 一、概述

文件管理器是 ModalChat 新增的核心功能，统一管理所有媒体文件的上传、删除、移动、重命名和目录组织。

## 二、核心概念

### 2.1 文件注册表（File Registry）

文件注册表是一个中央索引，维护所有文件的元数据与实际存储位置的映射：

```javascript
// 文件注册表条目
{
  id: 'reg_a1b2c3d4',                      // 注册表唯一 ID
  source: 'chat-images',                    // 来源: 'chat-images' | 'match-scoring' | 'file-manager'
  serverFilename: 'ChatImages_20260725_143015_123456.png',  // 服务端存储的真实文件名
  originalName: '我的照片.jpg',             // 用户上传时的原始文件名
  displayName: '海边日落',                   // 用户自定义展示名
  type: 'image',                            // 'image' | 'video'
  mimeType: 'image/png',
  relativePath: 'my-folder/',               // 相对于 files 根目录的路径（含尾部 /）
  fullServerPath: 'data/default-user/user/files/my-folder/ChatImages_20260725_143015_123456.png',
  fileSize: 1024000,
  uploadDate: 1718000000000,
  directory: '/my-folder/',                 // 所属目录
}
```

### 2.2 服务端真实文件名格式

```
{来源前缀}_{日期}_{时间}_{6位随机数}.{扩展名}
```

| 来源 | 前缀 | 示例 |
|------|------|------|
| chat-images 旧数据 | `ChatImages_` | `ChatImages_20260725_143015_123456.png` |
| MatchScoring 旧数据 | `MatchScoring_` | `MatchScoring_20260725_143015_123456.jpg` |
| 文件管理器新上传 | `MM_` | `MM_20260725_143015_654321.webp` |

### 2.3 存储根目录

所有文件存储在 `data/default-user/user/files/` 下。

### 2.4 目录结构

目录是**真实的服务器文件系统目录**，支持：
- 创建目录（在 files 根目录下创建子文件夹）
- 删除目录（递归删除空目录）
- 移动/重命名目录
- 目录树浏览

## 四、操作列表

| 操作 | 触发 | 实现 |
|------|------|------|
| 上传文件 | 点击上传按钮 | `file-service.uploadFile()` |
| 删除文件 | 选中后点删除 | `file-service.deleteFile()` + 清理注册表 |
| 移动文件 | 选中后点移动，选择目标目录 | `file-service.moveFile()` |
| 重命名文件 | 右键/双击文件名 | `file-service.renameFile()` |
| 创建目录 | 点击新建目录按钮 | `file-service.createDir()` |
| 删除目录 | 右键目录 | `file-service.deleteDir()` |
| 搜索文件 | 输入搜索关键词 | 过滤注册表 + 扫描目录 |
| 批量选择 | 复选框 | 全选/反选 |

## 五、与其他模块的交互

### 5.1 聊天图片（nav-chat-images）

- **新增规则图片**：打开文件管理器选择弹窗 → 用户勾选已有文件 → 保存注册表 ID
- **展示图片**：通过注册表 ID 查路径 → 渲染 `<img>`
- **删除规则图片**：仅移除注册表 ID 引用，不删实际文件

### 5.2 匹配打分（nav-match-scoring）

- **添加匹配文件**：打开文件管理器选择弹窗 → 勾选已有文件 → 保存注册表 ID
- **展示匹配结果**：通过注册表 ID 查路径 → 渲染
- **删除匹配文件引用**：仅移除引用，不删实际文件
