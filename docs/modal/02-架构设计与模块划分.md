## 三、模块职责详表

| 模块 | 职责 | 核心导出 | 预计行数 |
|------|------|---------|---------|
| `index.js` | 生命周期钩子、导航栏创建、事件注册 | `init`, `onDelete` | ~50 |
| `data.js` | 全局设置管理、文件注册表 CRUD、各模块数据初始化 | `loadSettings`, `saveSettings`, `getRegistry`, `addRegistryEntry` | ~300 |
| `shared/utils.js` | 通用工具函数 | `generateId`, `escapeHtml`, `debounce` | ~100 |
| `shared/file-service.js` | 服务端文件操作（上传/删除/移动/重命名/目录管理） | `uploadFile`, `deleteFile`, `moveFile`, `renameFile`, `createDir`, `deleteDir`, `listDir` | ~200 |
| `nav-chat-images/data.js` | 规则/规则集/角色集 CRUD（引用文件注册表 ID） | `getRulesData`, `addRule`, `updateRule` | ~150 |
| `nav-chat-images/matcher.js` | 正则匹配引擎（与旧版一致） | `performMatch`, `matchSingleRule` | ~200 |
| `nav-chat-images/rules-ui.js` | 规则界面渲染与事件绑定 | `renderRuleList`, `bindUIEvents` | ~450 |
| `nav-match-scoring/file-display.js` | 文件列表展示、筛选、排序 | `renderFileList`, `bindFileEvents` | ~300 |
| `nav-match-scoring/match-config.js` | 匹配配置滑条、存档管理 | `renderConfigPanel`, `bindConfigEvents` | ~300 |
| `nav-match-scoring/scorer.js` | 评分引擎（与旧版一致） | `scoreMessages`, `getLastResults` | ~500 |
| `nav-file-manager/file-manager-ui.js` | 文件管理器 UI（目录树+文件列表+操作栏） | `renderFileManager`, `bindManagerEvents` | ~500 |

## 五、关于文件引用机制

聊天图片和匹配打分不再直接上传/删除服务端文件。当它们需要图片时：

1. **批量新增** → 弹出文件管理器选择界面 → 用户从已有文件中选择 → 保存文件注册表 ID
2. **展示媒体** → 通过注册表 ID 查询文件路径 → 渲染
3. **删除规则/文件** → 仅删除元数据引用，不删除实际文件（文件管理器独立管理）
