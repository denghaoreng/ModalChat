# ModalChat 插件 — 架构设计与模块划分

> 编写日期：2026年7月25日 | 最后更新：2026年7月28日

## 一、项目结构

```
ModalChat/
├── manifest.json                  # 插件清单
├── index.js                       # ★ 入口：生命周期、导航栏创建、事件注册
├── style.css                      # 全局样式
├── settings.html                  # 扩展设置模板
│
├── core/                          # ★ 核心数据层（多文件存储）
│   ├── data.js                    # ★ 数据层 facade（currentSettings, loadSettings, saveSettings, 模块数据访问器）
│   ├── default-settings.js        # DEFAULT_SETTINGS、DEFAULT_ANIMATION_TYPES 等默认值
│   ├── data-migration.js          # 数据迁移（MatchScoring → ModalChat）
│   ├── file-storage.js            # ★ 文件 I/O（readJSON/writeJSON/deleteFile/hashStr/dirFile）
│   ├── registry-state.js          # ★ 注册表状态（_entryCache CRUD、脏追踪、增量保存）
│   └── directory-manager.js       # 目录管理（getDirectories/addDirectory/removeDirectoryRecursive）
│
├── shell/                         # ★ 导航栏与消息处理（从 index.js 拆分）
│   ├── drawer.js                  # ★ 导航栏 Drawer 创建 + 标签页切换调度
│   └── message-handler.js         # ★ 事件回调（MESSAGE_RECEIVED / SWIPED / CHAT_CHANGED 等）
│
├── shared/                        # 共享模块
│   ├── utils.js                   # 工具函数（generateId, escapeHtml, detectFileType 等）
│   ├── file-service.js            # ★ 文件服务（上传/删除/移动/重命名/目录CRUD）
│   ├── file-enlarge.js            # 全屏放大查看器（图片/视频/音频）
│   ├── file-icons.js              # 文件图标和类型标签
│   ├── popup-type.js              # 弹窗类型常量
│   ├── bounce-editor/             # 果冻弹跳预设可视化编辑器

│   │   ├── render.js              # 渲染管线
│   │   └── interaction.js         # 交互事件处理
│   └── image-drag-physics/        # 图片拖拽变形物理引擎
│       ├── index.js               # 导出 hub

│
├── nav-chat-images/               # 「聊天图片」标签页
│   ├── domain/                    # 数据层（CRUD）
│   │   ├── index.js               # re-export hub
│   │   ├── char-sets.js           # 角色集 CRUD（含级联删除规则集/规则）
│   │   ├── rule-sets.js           # 规则集 CRUD（含级联删除规则）
│   │   ├── rules.js               # 规则 CRUD
│   │   └── helpers.js             # 工具函数（getEnabledRules, addImageToRule 等）
│   ├── matcher/                   # ★ 正则匹配引擎
│   │   ├── index.js               # re-export hub
│   │   ├── engine.js              # ★ 匹配主逻辑（按规则集分组匹配，返回拍平数组）

│   │   ├── queue.js               # 队列定时器管理（generation 追踪/清理）

│   │   ├── rule-sets.js           # 规则集列表渲染（角色集绑定/搜索/排序/分页）
│   │   ├── rules.js               # 规则列表渲染（规则集筛选/搜索/排序/分页/展开折叠/图片缩略图）

│   ├── carousel/                  # ★ 聊天图片轮播渲染（匹配打分版简化）
│   │   ├── index.js               # re-export hub
│   │   ├── bubble.js              # ★ 聊天气泡轮播渲染（基于插位槽配置）
│   │   └── persist.js             # 持久化/恢复/清理（chat.extra）
│   └── image/                     # （保留目录，未使用）
│
├── nav-match-scoring/             # 「匹配打分」标签页
│   ├── index.js                   # 薄导入层（导出 renderMatchScoring, bindMatchScoringEvents）
│   ├── drawer.js                  # ★ 子导航栏渲染（文件展示/匹配配置/轮播配置）
│   ├── file-display.js            # ★ 文件展示 UI（上传/搜索/筛选/排序/分页/批量操作）
│   ├── match-config.js            # ★ 匹配配置 UI（权重滑条/存档管理/停用词/关联词）
│   ├── scorer.js                  # ★ 评分引擎 re-export hub（向后兼容）
│   ├── carousel-config.js         # ★ 轮播插位配置（插位槽/类型/时长/动画/折叠状态保持）
│   ├── match-chat-results.js      # ★ 匹配结果 re-export hub
│   ├── popup-config.js            # 配置弹窗 re-export hub
│   │
│   ├── scorer/                    # ★ 评分引擎子模块（从 scorer.js 拆分）
│   │   ├── index.js               # re-export hub
│   │   ├── scoring.js             # ★ 评分编排（scoreMessages / filterResultsForChat）
│   │   ├── ngram.js               # ★ N-gram 索引构建与匹配（单次扫描优化）
│   │   ├── text.js                # 文本预处理（cleanText）
│   │   ├── tag.js                 # 标签匹配（支持正则标签）
│   │   ├── type.js                # 文件类型匹配 + 上下文类型偏好
│   │   ├── relation.js            # 关联词匹配
│   │   ├── fuzzy.js               # 字符模糊匹配
│   │   ├── stopwords.js           # 停用词匹配
│   │   └── cache.js               # 评分结果缓存（get/set/clearLastResults）
│   │
│   ├── match-chat-results/        # ★ 匹配结果渲染子模块
│   │   ├── index.js               # re-export hub
│   │   ├── panel.js               # 结果面板渲染（抽屉内）
│   │   ├── bubble.js              # ★ 聊天气泡匹配结果渲染 + 轮播（含弹跳动画、暂停恢复）
│   │   └── persist.js             # ★ 持久化/恢复/清理（chat.extra，rAF 分批渲染）
│   │
│   └── popup/                     # 配置弹窗子模块
│       ├── batch.js               # 批量新增弹窗
│       ├── keywords.js            # 关键词编辑弹窗
│       ├── relations.js           # 关联词编辑弹窗
│       ├── stopwords.js           # 停用词编辑弹窗
│       └── tags.js                # 标签筛选弹窗
│
├── nav-file-manager/              # 「文件管理」标签页
│   ├── index.js                   # 薄导入层（导出 renderFileManager, bindManagerEvents 等）
│   ├── file-render.js             # ★ 文件管理器渲染（目录树/文件列表/面包屑/分页）
│   ├── file-events.js             # ★ 事件绑定（上传/删除/移动/重命名/目录操作/批量修改）
│   ├── file-state.js              # ★ 状态管理（currentDir/选中/分页/排序/搜索/视图模式）
│   ├── file-url.js                # 根据注册表条目获取可访问 URL（async）
│   ├── file-picker-popup.js       # 文件选择器弹窗（供其他模块调用）
│   └── file-registry.js           # 注册表查询操作（搜索/类型/来源）
│
├── nav-general-settings/          # 「通用配置」标签页
│   ├── index.js                   # 薄导入层（导出 renderGeneralSettings, bindGeneralEvents）
│   ├── settings-ui.js             # ★ 子导航调度（UI配置/轮播类型/动态图预设）
│   ├── ui-config.js               # UI 配置子页（图片尺寸/媒体尺寸/背景颜色/透明度）
│   ├── anim-types.js              # 轮播类型编辑子页（创建/编辑/删除 @keyframes，含缓动函数文档）
│   └── bounce-presets/            # 动态图预设子页
│       ├── index.js               # 导出 hub
│       ├── bounce-presets.js      # ★ 核心逻辑（编辑器实例/渲染/事件）
│       ├── fullscreen.js          # 全屏画布编辑器
│       └── params.js              # 参数面板渲染与输入处理
│
└── docs/
    ├── docs-main/                  # 插件开发通用文档
    ├── bug/                        # Bug 修复记录
    └── modal/                     # 本文档目录
```

## 三、模块职责详表

| 模块 | 职责 | 核心导出 |
|------|------|---------|
| `index.js` | 生命周期钩子、导航栏 Drawer 创建、4 个标签页切换调度、SillyTavern 事件监听/回调、状态缓存、debounce 保存 | `init`, `onDelete`, `onEnable`, `onDisable` |
| `core/data.js` | 多文件 JSON 存储（读写/防抖保存）、注册表按目录分文件懒加载、海量条目支持（5万+）、各模块数据访问器、虚拟目录管理、数据迁移补全 | `loadSettings`, `saveSettings`, `addRegistryEntry`, `getRegistryById`, `searchRegistry` 等 |
| `shared/utils.js` | ID 生成、HTML 转义、文件类型检测、图标映射、文件大小/日期格式化、防抖、服务端文件名生成、颜色转换 | `generateId`, `escapeHtml`, `detectFileType`, `formatFileSize`, `generateServerFilename` |
| `shared/file-service.js` | 服务端文件上传/删除/批量操作、注册表移动/重命名（逻辑）、目录创建/删除（含递归子目录清理） | `uploadFile`, `uploadFiles`, `deleteFile`, `deleteFiles`, `moveFile`, `renameFile`, `createDirectory`, `deleteDirectory` |
| `shared/file-enlarge.js` | 图片/视频/音频全屏放大查看器（含双指缩放、拖拽平移、事件冒泡防护） | `showFileEnlarge` |
| `shared/file-icons.js` | 文件图标映射表、类型标签/图标获取 | `getTypeLabel`, `getFileIcon` |
| `shared/popup-type.js` | SillyTavern 弹窗类型常量 | `POPUP_TYPE` |
| `shared/bounce-editor/` | BounceEditor 类：画布渲染、点/骨骼编辑、撤销栈、全屏编辑 | `BounceEditor` |
| `shared/image-drag-physics/` | 基于 SVG feDisplacementMap 的果冻弹跳物理引擎 | `setupDragDeformation`, `autoBounce` |
| `nav-chat-images/domain/char-sets.js` | 角色集 CRUD（含级联删除规则集和规则） | `getCharSets`, `addCharSet`, `deleteCharSet` |
| `nav-chat-images/domain/rule-sets.js` | 规则集 CRUD（含级联删除规则） | `getRuleSets`, `addRuleSet`, `deleteRuleSet` |
| `nav-chat-images/domain/rules.js` | 规则 CRUD | `getRules`, `getRuleById`, `addRule`, `updateRule`, `deleteRule` |
| `nav-chat-images/domain/helpers.js` | 启用规则过滤、图片引用增删、URL 获取 | `getEnabledRules`, `addImageToRule`, `removeImageFromRule`, `getImageUrlByRegistry` |
| `nav-chat-images/matcher/engine.js` | ★ 匹配主逻辑：按规则集顺序分组匹配，返回拍平图片项数组（不再直接操作 DOM） | `performMatch` |
| `nav-chat-images/matcher/single-rule.js` | 单条规则匹配：正则测试 + 加权随机选图 + 解析图片 URL（async） | `matchSingleRule` |
| `nav-chat-images/matcher/queue.js` | 队列定时器管理：generation 追踪（滑动过期）、定时器清理 | `clearImageTimer`, `clearAllImageTimers`, `cancelPendingMatch`, `getGeneration` |
| `nav-chat-images/matcher/utils.js` | 加权随机选择、正则安全化 | `selectImageByWeight`, `sanitizeRegex` |
| `nav-chat-images/ui/index.js` | ★ 聊天图片主渲染入口 + 子导航调度（角色集/规则集/规则/轮播设置） + 全部事件绑定 | `renderChatImages`, `bindChatImagesEvents` |
| `nav-chat-images/ui/char-sets.js` | 角色集列表渲染（搜索按钮触发、内联编辑、关联规则集计数） | `renderCharSets`, `triggerCSSearch`, `triggerCSClear` |
| `nav-chat-images/ui/rule-sets.js` | 规则集列表渲染（角色集绑定筛选、搜索按钮触发、排序、分页、内联编辑） | `renderRuleSets`, `saveRsCharSelect`, `triggerRSSearch`, `setRSPage`, `setRSPageSize` |
| `nav-chat-images/ui/rules.js` | 规则列表渲染（规则集筛选、搜索按钮触发、排序、分页、展开折叠、图片缩略图 + 权重滑块） | `renderRules`, `saveRulesetFilter`, `triggerRuleSearch`, `setRulePage`, `setRulePageSize` |
| `nav-chat-images/ui/carousel-settings.js` | 轮播配置 UI（简化版：无媒体类型/无数量/无秒/无最低分，仅总时长/动画/点击动作） | `renderCarouselSettings` |
| `nav-chat-images/popup/batch.js` | 批量新增（调用文件选择器 + 创建规则引用）、批量修改（时长/正则） | `showBatchAddPopup`, `showBatchEditPopup` |
| `nav-chat-images/popup/regex-help.js` | 正则表达式手册弹窗 | `showRegexHelp` |
| `nav-chat-images/carousel/bubble.js` | ★ 聊天气泡聊天图片轮播渲染（基于插位槽配置，与匹配打分独立 div） | `renderCIResults` |
| `nav-chat-images/carousel/persist.js` | 聊天图片结果持久化到 chat.extra、恢复、清理 | `persistCIResults`, `restoreCIResults`, `cleanupStaleCIResults` |
| `nav-match-scoring/drawer.js` | 匹配打分子导航渲染（文件展示/匹配配置/轮播配置 三个子标签页，含结果面板） | `renderMatchScoring`, `bindMatchScoringEvents` |
| `nav-match-scoring/file-display.js` | 文件列表展示（上传/搜索按钮触发/批量新增/筛选/排序/分页可填/标签筛选/网格设置） | `renderFileDisplay`, `bindFileDisplayEvents` |
| `nav-match-scoring/match-config.js` | 匹配配置 UI：权重滑条、配置存档（新建/保存/加载/删除）、停用词/适配词/关联词、类型关键词 | `renderMatchConfig`, `bindMatchConfigEvents` |
| `nav-match-scoring/scorer.js` | 评分引擎：N-gram 分词、多维加权（来源/内容/标签/关联/停用词/字符模糊/类型偏好）、随机抖动、Top-N 过滤 | `scoreMessages`, `filterResultsForChat`, `cleanText`, `getLastResults` |
| `nav-match-scoring/carousel-config.js` | 轮播插位配置：多层插位、类型筛选、展示数量/时长/最低分、动画类型选择、折叠状态保持 | `renderCarouselConfig`, `bindCarouselEvents` |
| `nav-match-scoring/match-chat-results/panel.js` | 结果面板渲染（抽屉内，按类型分组排名） | `renderResultsPanel` |
| `nav-match-scoring/match-chat-results/bubble.js` | ★ 聊天气泡匹配结果渲染 + 轮播（插位槽/动画/类型分组/暂停恢复/弹跳动画） | `renderChatResults` |
| `nav-match-scoring/match-chat-results/persist.js` | 持久化/恢复/清理（chat.extra，rAF 分批渲染） | `persistChatResults`, `restoreChatResults`, `cleanupStaleExtraRefs`, `cleanupAllChatResults` |
| `nav-match-scoring/popup-config.js` | 配置弹窗集合：关联词编辑、停用词编辑、类型关键词编辑、配置手册、标签筛选 | 弹窗函数 |
| `nav-match-scoring/popup/batch.js` | 批量新增弹窗：调用文件选择器、设置共用名称/标签/内容 | `showBatchAddPopup` |
| `nav-file-manager/file-render.js` | 文件管理器渲染：活动目标支持、目录树/文件列表/面包屑/分页/排序，支持 simple/detail 两种视图 | `renderFileManager`, `setActiveFileManagerTarget` |
| `nav-file-manager/file-events.js` | 文件管理器事件绑定（事件委托）：上传/删除/重命名/目录创建删除、文件详情弹窗、全选/反选、批量 | `bindManagerEvents`, `enterSelectionMode` |
| `nav-file-manager/file-state.js` | 模块级状态变量：当前目录、选中集合、分页、排序、视图模式、搜索模式 | 状态变量 + setter 函数 |
| `nav-file-manager/file-url.js` | 根据注册表条目或 ID 获取可访问 URL（async） | `getFileUrl` |
| `nav-file-manager/file-picker-popup.js` | 文件选择器弹窗（供其他模块调用）：全功能文件管理器界面，确认后返回选中条目 | `showFilePickerPopup` |
| `nav-file-manager/file-registry.js` | 注册表查询操作：按来源/名称模糊搜索、获取所有类型/来源 | `searchRegistry`, `getAllTypes`, `getAllSources` |

## 五、关于文件引用机制

聊天图片和匹配打分不再直接上传/删除服务端文件。当它们需要图片时：

1. **批量新增** → 调用 `showFilePickerPopup()` 弹出文件管理器选择界面 → 用户从已有文件中选择 → 保存文件注册表 ID
2. **展示媒体** → 通过注册表 ID 查询文件路径（`getRegistryById()` + `getFileUrl()`）→ 渲染
3. **删除规则/文件** → 仅删除元数据引用，不删除实际文件（文件管理器独立管理）
