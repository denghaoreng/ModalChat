# ModalChat 插件 — 数据存储与兼容指南

> 编写日期：2026年7月25日 | 最后更新：2026年7月27日

## 一、数据存储架构

ModalChat **不再使用** SillyTavern 的 `extensionSettings` 存储数据。所有数据存储在 `/user/files/` 目录下（通过 SillyTavern 文件系统 API 读写），以多个独立 JSON 文件组织。

### 1.1 文件清单

| 文件名 | 存储内容 | 说明 |
|--------|---------|------|
| `ModalChat_settings.json` | 目录列表、文件夹元数据、最后标签页、通用配置 | 轻量级，频繁读写 |
| `ModalChat_chat-images_data.json` | `navChatImages`（角色集/规则集/规则） | 聊天图片模块专属 |
| `ModalChat_match-scoring_data.json` | `navMatchScoring`（文件列表/权重/停用词/关联词/配置存档/动画类型/轮播配置等） | 匹配打分模块专属 |
| `ModalChat_reg-index.json` | 轻量索引 `{ id: directory }` | 始终在内存中 |
| `ModalChat_dir_XXXXXXXX.json` | 按目录分文件的注册表条目数组 | 每个目录一个文件，按需懒加载 |

### 1.2 读写机制

```javascript
// 读：通过 /user/files/ 静态 URL fetch
async function readJSON(name) {
    return fetch('/user/files/' + name).then(r => r.json());
}

// 写：通过 /api/files/upload API
async function writeJSON(name, data) {
    const b64 = btoa(JSON.stringify(data));
    return fetch('/api/files/upload', {
        method: 'POST',
        body: JSON.stringify({ name, data: b64 }),
    });
}
```

### 1.3 防抖保存

所有写操作通过 `debouncedSave()` 防抖（300ms）批量执行，避免频繁写入。

## 二、数据迁移（运行时补全）

ModalChat 在 `core/data.js` 的 `loadSettings()` 中调用 `core/data-migration.js` 的 `migrateMatchScoringData()` 函数，在启动时自动补全旧数据中缺失的字段，确保结构完整。此函数**不会**从旧插件导入数据，而是填补当前已保存数据中的空缺。

### 迁移内容

| 补全字段 | 说明 |
|---------|------|
| `typeVideoKeywords` | 视频类型关键词（如为空则填充默认值） |
| `typeImageKeywords` | 图片类型关键词（同上） |
| `typeAudioKeywords` | 音频类型关键词（同上） |
| `animationTypes` | 动画类型数组（补全缺失的 keyframes/timingFunction，添加未定义的默认类型） |
| `slots[].clickAction` | 插位点击操作（默认为 `'enlarge'`） |

## 四、兼容性说明

- ModalChat 的数据独立存储，与旧插件数据互不影响
- 旧插件文件夹保留，不做任何修改
- 如果卸载 ModalChat，旧插件的功能不受影响
- 升级 ModalChat 时会自动补全数据结构（通过 `migrateMatchScoringData`）
