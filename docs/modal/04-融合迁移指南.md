# ModalChat 插件 — 融合迁移指南

> 编写日期：2026年7月25日

## 一、自动迁移流程

首次加载 ModalChat 时，自动执行数据迁移：

```
ModalChat init()
      │
      ▼
┌────────────────┐     NO      ┌──────────────────┐
│ 检测旧数据存在?  │ ───────→   │ 全新安装，跳过迁移 │
└───────┬────────┘             └──────────────────┘
        │ YES
        ▼
┌─────────────────────────────────────┐
│ 第一步：迁移 chat-images 数据        │
│ 1. 读取 extensionSettings['chat-images'] │
│ 2. 遍历所有规则中的图片              │
│ 3. 为每张图片创建文件注册表条目      │
│ 4. 复制 rules/ruleSets/charSets      │
│    到 ModalChat 数据                 │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│ 第二步：迁移 MatchScoring 数据       │
│ 1. 读取 extensionSettings['match-scoring'] │
│ 2. 遍历所有文件                      │
│ 3. 为每个文件创建文件注册表条目      │
│ 4. 复制权重/配置/存档到 ModalChat    │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│ 第三步：标记迁移完成                 │
│ 设置 modalChat.migrationComplete = true │
│ 保存设置                            │
└─────────────────────────────────────┘
```

## 二、数据映射

### 2.1 chat-images → ModalChat

| chat-images 字段 | ModalChat 字段 | 说明 |
|-----------------|---------------|------|
| `rules.rules` | `navChatImages.rules` | 规则列表 |
| `rules.ruleSets` | `navChatImages.ruleSets` | 规则集 |
| `rules.charSets` | `navChatImages.charSets` | 角色集 |
| `rules.rules[].images[].path` | → 文件注册表 | 图片路径注册 |
| `settings.imageWidth` | `navGeneralSettings.imageWidth` | 图片宽度 |
| `settings.imageHeight` | `navGeneralSettings.imageHeight` | 图片高度 |
| `settings.frameBackgroundColor` | `navGeneralSettings.frameBgColor` | 背景色 |
| `settings.frameBackgroundOpacity` | `navGeneralSettings.frameBgOpacity` | 透明度 |

### 2.2 MatchScoring → ModalChat

| MatchScoring 字段 | ModalChat 字段 | 说明 |
|------------------|---------------|------|
| `files` | → 文件注册表 | 文件列表注册 |
| `weights` | `navMatchScoring.weights` | 权重配置 |
| `stopWords` | `navMatchScoring.stopWords` | 停用词 |
| `relations` | `navMatchScoring.relations` | 关联词 |
| `weightProfiles` | `navMatchScoring.weightProfiles` | 配置存档 |
| `mediaWidth` | `navGeneralSettings.mediaWidth` | 媒体宽度 |
| `mediaHeight` | `navGeneralSettings.mediaHeight` | 媒体高度 |

## 三、数据格式

### 3.1 ModalChat 全局数据

```javascript
extensionSettings['modal-chat'] = {
    // ===== 迁移标记 =====
    migrationComplete: false,

    // ===== 文件注册表 =====
    fileRegistry: [
        {
            id: 'reg_xxx',
            source: 'chat-images',
            serverFilename: 'ChatImages_...png',
            originalName: '...',
            displayName: '...',
            type: 'image',
            relativePath: '...',
            fullServerPath: '...',
            fileSize: 0,
            uploadDate: 0,
            directory: '/',
        }
    ],

    // ===== 聊天图片模块数据 =====
    navChatImages: {
        charSets: [],
        ruleSets: [],
        rules: [],
        // 规则图片引用注册表 ID
        // rules[].images = [{ registryId: 'reg_xxx', weight: 50 }]
    },

    // ===== 匹配打分模块数据 =====
    navMatchScoring: {
        files: [],  // 引用注册表 ID
        weights: { ... },
        stopWords: [...],
        relations: [...],
        weightProfiles: [],
    },

    // ===== 通用配置 =====
    navGeneralSettings: {
        imageWidth: 500,
        imageHeight: 500,
        mediaWidth: 400,
        mediaHeight: 400,
        frameBgColor: '#000000',
        frameBgOpacity: 1,
    },
};
```

## 四、兼容性

- 旧插件文件夹保留，不做任何修改
- 旧插件数据只读，迁移后 ModalChat 完全接管
- 如果需要回退，ModalChat 的数据独立于旧插件，互不影响
